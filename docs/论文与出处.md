# 论文、数据与出处

> 可核查性原则：下列每一条都注明用途与出处；「本实现差异」如实说明取舍。

## 1. 数据集

| 项 | 内容 |
|---|---|
| 数据集 | **KuaiRec**（快手短视频推荐日志） |
| 论文 | Gao, C. et al. *KuaiRec: A Fully-observed Dataset and Insights for Evaluating Recommender Systems.* CIKM 2022 |
| 获取 | Zenodo record `18164998`（KuaiRec Dataset with Raw Features）；GitHub: `chongminggao/KuaiRec` |
| 许可 | Zenodo 记录标注 **CC-BY-4.0**；GitHub 仓库徽章标注 CC BY-SA 4.0（两处口径不一致，本项目双标注并以 Zenodo 为准） |
| 关键性质 | 小矩阵 1,411×3,327、99.6% 稠密（全观测）；大矩阵 7,176×10,728、12,530,806 条（16.3%） |
| 本项目使用 | 大矩阵 → 训练序列（时间切分）；小矩阵 → 全观测无偏评估；caption/类目 → 语义 ID 内容特征 |

**已知数据特性（校验证实）**：small 矩阵 3.9% 缺 timestamp；watch_ratio 有回放循环极值（最大 573）；caption 文件需 python 解析引擎。

## 2. 方法论文

| 论文 | 出处 | 本项目用途 | 本实现差异（如实） |
|---|---|---|---|
| RQ-VAE | Lee, D. et al. *Autoregressive Image Generation using Residual Quantization.* CVPR 2022 | 残差量化把内容特征变为层次语义 ID | 1) 用轻量 MLP（非图像 VAE）；2) 输入为 TF-IDF+SVD 特征（非图像/大模型嵌入）；3) 增加死码重启与特征标准化 |
| TIGER | Rajput, S. et al. *Recommender Systems with Generative Retrieval.* NeurIPS 2023 | 语义 ID + seq2seq 生成式检索的整体范式；受限解码思想 | 1) 内容编码器从 Sentence-T5 降级为字符 n-gram TF-IDF+SVD；2) 碰撞从"追加额外位"改为"解码时展开候选组"；3) 训练规模缩小到 CPU 预算（150k 样本 × 1 epoch） |
| HSTU | Zhai, Y. et al. *Actions Speak Louder than Words: Trillion-Parameter Sequential Transducers for Generative Recommendations.* ICML 2024 | "行为即 token"思路（本项目把 watch_ratio 分桶作为行为 token）；生成式推荐的推理成本判断 | 未实现 HSTU 结构；仅采用"行为 token 化"思想（行为 token 消融列为待运行） |
| OneRec | Kuaishou, 2025（arXiv，以论文为准） | 端到端生成式推荐的工业案例；推理成本判断 | 未实现端到端列表生成（列为方案三备选，未选） |
| LightGCN 等 | 见《推荐系统讲义》附录 C | 背景调研 | 未使用 |
